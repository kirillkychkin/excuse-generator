# Генератор оправданий опоздания

Учебный проект по дисциплине «Разработка приложений на Python».

Веб-приложение подбирает правдоподобное оправдание опоздания на занятие, учитвая контекст:

- **на сколько минут** опоздал студент — «автобус задержался» годится для 5 минут, но не для часа;
- **на какой предмет** — на программировании уместно «упал WSL», на физкультуре «забыл форму»;
- **историю пользователя** — недавние оправдания и темы не повторяются, а преподаватель
  конкретного предмета «помнит», что он уже слышал;
- **обратную связь** — оправдания, которые «не сработали», предлагаются реже;
- **время суток** — «проспал» уместно утром, а не вечером;
- **частоту опозданий** — если студент опаздывает слишком часто, приложение предупреждает
  об этом и предлагает только самые убедительные варианты.
