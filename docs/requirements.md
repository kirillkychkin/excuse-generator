# Постановка задачи

## Проблема

Студенты иногда опаздывают на занятия, и каждый раз приходится придумывать объяснение.
Однообразные оправдания быстро теряют убедительность: преподаватель запоминает,
что «автобус сломался» уже в третий раз за неделю. Нужен помощник, который подберёт
уместное и не повторяющееся оправдание с учётом ситуации.

## Цель

Разработать веб-приложение с REST API, которое генерирует оправдание опоздания
на основе контекста и истории пользователя, и довести его до развёртывания
(Docker, CI/CD).

## Пользователи

- **Студент** — вводит своё имя, предмет и время опоздания, получает оправдание,
  отмечает, сработало ли оно, просматривает историю и статистику.
- **Внешний клиент API** (например, бот или мобильное приложение) — использует те же
  функции через JSON API.

## Функциональные требования

| №    | Требование |
|------|------------|
| FR-1 | Пользователь идентифицируется по имени (без пароля); при первой генерации создаётся автоматически. |
| FR-2 | Пользователь выбирает предмет из справочника; у каждого предмета есть категория (программирование, математика, физкультура, гуманитарные, естественные науки). |
| FR-3 | Пользователь указывает время опоздания в минутах (1–180). Система относит его к категории: небольшое (≤5), среднее (6–15), большое (16–40), огромное (>40). |
| FR-4 | Система выбирает шаблон оправдания, подходящий по времени опоздания, категории предмета и времени суток. |
| FR-5 | Шаблоны из последних 5 генераций пользователя не предлагаются; темы последних 3 генераций предлагаются реже. |
| FR-6 | Шаблон, который пользователь уже использовал для того же предмета, предлагается реже. |
| FR-7 | Пользователь может отметить, сработало ли оправдание; это влияет на дальнейший выбор. |
| FR-8 | Система считает число опозданий за последние 7 дней и определяет уровень риска (низкий / средний / высокий). При высоком уровне предлагаются только самые убедительные оправдания и выводится предупреждение. |
| FR-9 | Каждая генерация сохраняется в историю; доступен просмотр истории и статистики (всего опозданий, за неделю, среднее время, любимая тема, доля сработавших). |
| FR-10 | Все функции доступны через REST API с автоматической документацией (Swagger) и через веб-страницу. |
